## What Oxim?

Oxim is a web bundler plugin that optimizes your images by losslessly/lossily compressing them.

The compressor is powered by a blazingly fast image processing engine called [@napi-rs/image](https://image.napi.rs/).

Currently we are only supporting Vite. However, more bundlers will be supported in the future.
