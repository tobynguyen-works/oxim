# Oxim

Oxim is a high-performance image optimization plugin for modern web frameworks, powered by [@napi-rs/image](https://image.napi.rs/).

For more information, check out at our [website][website-url].

## ✍️ Contribute

See [CONTRIBUTING][contributing-guide] for guidance.

If you are unable to contribute by code, you can still participate by:

- Add a GitHub Star to the project.
- Follow me on [X][x-url] and post about this project.
